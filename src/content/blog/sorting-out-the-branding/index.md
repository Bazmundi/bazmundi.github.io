I decided to clean up the branding on my vblog, including matching fonts and font colours between the intro vids and the text on the titles I applied using OpenShot.



I had to trawl the net to find a way to do this permanently, there are a raft of video and "help" at the [OpenShot site](https://cdn.openshot.org/static/files/user-guide/titles.html), but none really explain correctly the mechanics of the difference between project and user title templates.



The "Help" didn't, of course, but I did learn that titles in OpenShot are any valid svg file (which is why they use InkScape as the default "advance" title editor). The problem with the "help" was that the supposed directory suggested did not exist. It did not help creating it under that location, and it only appeared to relate to the work in the current project. I ended up tracking into the install directory for OpenShot and using InkScape on copies of the starting templates I was using. I now have a way to create my own title templates for the brand, you can still use the "advanced" editor option in OpenShot to make on the fly titles for the current project.



I have now set up two default omm titles. One for the run of the mill videos and one for RANTS!



Luckily placeit.dev includes fonts and their colours in the metadata, so I could match both.



Just now the chore of re-posting the first dozen videos to update with the new fonts.



Worked out a trick to also bleed the trailing videos into the hot exploding ball. I have added an aggressive fade to the end of the second to last, and I add a 0.5 second blank (black) between the second to last and the KABOOM!
