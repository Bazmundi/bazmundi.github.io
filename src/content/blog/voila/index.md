Okay, so a little fiddling and changing a couple of set parameters and I have code running on my Samsung S2 that will unwrap a Bloggie lens.
Based on code by [Flong](http://www.flong.com/blog/2010/open-source-panoramic-video-bloggie-openframeworks-processing/) but running against camera and not a saved image.
Now a bit of work to port ideas from [roborealm](http://www.roborealm.com/tutorial/Obstacle_Avoidance/slide010.php) to turn this into an obstacle avoidance sensor.  Will have to find or code related image processing in Processing or Java.  Although, might have found the best library in [BOOF](http://boofcv.org/index.php?title=Main_Page)!  BOOF has processing library (already just now installed on my machine), camera calibration, structure from motion (OMG!), Fiducials (read Markers) (OMG!).
So, ready, steady GO!
