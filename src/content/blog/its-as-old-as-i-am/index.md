I was thinking about additional languages to play with in jupyter. I found they have elixir and a few others, including chapel. Both elixir and chapel need be set up on my linux box. I was hoping for Windoze 10.



I did find [Dyalog](https://www.dyalog.com/)'s [APL](https://en.wikipedia.org/wiki/APL_(programming_language)) and thought, I did always want to play with that language BUT thought it was long dead. (my first programming language was LISP ;) ).



The APL kernel junk is [here](https://github.com/Dyalog/dyalog-jupyter-kernel).



So, it was straight forward to install, though I had to hand install since my jupyter install is a virtualenv and I had to note that the install bat made some assumptions about the APPDATA directory structure that was not apt.



All good, I also found a nifty javascript hook into your browser to provide the [APL symbols](https://abrudz.github.io/lb/apl), though it doesn't set them out as a keyboard ***\*\*groan\*\****.
